# Brand Book Konjac Massa MF · fonte do Claude Design

Design system da marca no formato nativo do Claude Design (Design Components): 9 artboards `.dc.html`, layout em `canvas.json` e imagens referenciadas por nome relativo.

| Arquivo | Artboard |
|---|---|
| `Main.dc.html` | Capa: logo, tese e território |
| `Paleta.dc.html` | Paleta master + cores do site |
| `Tipografia.dc.html` | Logo script, Inter (site), lettering de vídeo |
| `LinhaBox.dc.html` | Linha BOX com cor por corte |
| `Claims.dc.html` | Claims oficiais da embalagem |
| `Narrativa.dc.html` | Estrutura narrativa da casa |
| `Pilares.dc.html` | 6 pilares de conteúdo (v1) |
| `Conversao.dc.html` | Jornada de conversão e CTAs |
| `VozEdicao.dc.html` | Voz do perfil e assinaturas de edição |

Imagens: `logo.png` (logo oficial, fundo transparente) e `box-*.webp` (renders das 5 caixas).

- Para importar no Claude Design: use esta pasta como fonte do projeto (os `.dc.html` são os artboards; `canvas.json` posiciona e define o launch).
- Canvas publicado e editável (Artifact): mantido pela sessão do estúdio; a versão fonte é sempre esta pasta.
- Conteúdo canônico em texto: `../BRAND.md`. Assets em alta: `../logotipo-konjac-massa-mf.png` (32 KB), `../logotipo-konjac-massa-mf-vetor.pdf` e `../embalagens/`.
